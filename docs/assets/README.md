# Repository screenshots

These images show the actual gogosling development UI, captured on 2026-10-13.

- `start-en.jpg` (1280 × 720): the start page, project navigation, and local task controls.
- `workbench-en.jpg` (1440 × 720): a synthetic release brief, its conversation, and the saved Markdown document editor. The follow-up in the composer is an unsent draft.

The demo does not contain personal task history, private file paths, or credentials. The displayed model name is a demo label, not a shipped model.

These are browser captures of the application, not generated mockups. Refresh them when the corresponding workflow changes. The Gosli logo source is documented in [the brand assets](../../apps/web/public/brand/README.md).

## Suggested social preview

This is a design brief; a custom social preview has not been uploaded as part of this update.

- Use a 1280 × 640 image with an opaque white or sky-blue background. Keep the exported PNG or JPEG below 1 MB, following [GitHub's preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
- Put the gogosling wordmark and **Bring the brief. Leave with a file.** on the left. Keep Gosli small enough that the product remains the focus.
- Use a crop of the actual conversation and saved-result editor on the right. Keep Save/Export visible and avoid a collage of unrelated screens.
- Add **Built in Canada by Gogosling.ca** below the headline. Use brand blue `#2867BF` for emphasis, not a large flag or extra badges.
- Keep important text away from the edges and check it at thumbnail size. Do not include star counts, performance rankings, or claims about memory savings without measurements.
