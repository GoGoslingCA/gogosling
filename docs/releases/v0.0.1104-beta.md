# gogosling Beta 0.0.1104

**Keep your documents beside the work.**

gogosling is an open-source desktop AI workspace developed by [Gogosling.ca](https://gogosling.ca), a Canadian company. Bring your own model connection. No gogosling account is required.

This beta adds a sidebar list for Markdown, Word documents, and webpages. Switch between them without losing your task or result draft. The desktop mounts the selected file viewer and keeps at most one webpage view.

## What changed

- **Fewer pauses when reading.** Dense Markdown and Word tables render in bounded pages. Large Markdown files keep their reading layout; source text remains available.
- **Less duplicated data.** Plain Word paragraphs no longer send the same content twice in the preview response. Canceling a large Office read interrupts XML processing promptly.
- **Close means close.** Closing the active webpage releases its view, proxy listener, and connections. Switching pages preserves a bounded connection pool; inactive tabs do not each keep a browser view alive.
- **A quieter window.** The Mac title bar joins the app canvas. Dialogs use spacing instead of extra header and footer rules.
- **Ready-to-run packaging.** The installer includes the daemon, Python runtime, worker, brand icon, and third-party license notices.

## Measured, with limits

![Local Word preview timing](../assets/preview-performance.svg)

In a local 70-table Word fixture, median warm switch time fell from **340.4 ms to 71.5 ms**. The first page went from **7,770 to 1,110 DOM nodes**. Each build used ten warm switches for this file, on the same Apple M3 with 16 GiB memory and a fixed 1280 × 900 viewport. Timing runs from the click event to two animation frames after content mounts; it is not a screen-photon measurement or a general speed guarantee.

The native webpage host also released all guest views, proxy sockets, and workers after closing. Its base processes and temporary session remain while the app is running. Native page loads still show some long-tail waits; no across-the-board browser-speed or energy-saving claim is made. [Method, raw samples, and remaining limits](../reports/2026-10-13-performance-and-release.md).

## Download and install

This prerelease provides a **macOS Apple Silicon (arm64)** DMG. Windows, Linux, and Intel Mac installers are not included. Source archives are available on the release page.

1. Download the DMG, `SHA256SUMS.txt`, and `runtime-manifest.json` from this release.
2. In their download folder, run `shasum -a 256 -c SHA256SUMS.txt` to compare their bytes with the published checksums. A matching checksum is not a Developer ID signature or Apple notarization.
3. Open the DMG and move gogosling to Applications.
4. Launch the app and add a model connection in Settings. No separate Go, Node.js, Python, or uv installation is needed.

**The installer is unsigned and not notarized.** macOS may block its first launch. Review [Apple's guidance for opening apps safely](https://support.apple.com/en-ca/102445) before deciding whether to allow it; do not disable system-wide security checks. The bundle declares macOS 13 as its minimum; this release was tested on macOS 27 with Apple Silicon, not every intervening OS version.

## Before you use it

- Local project storage does not make remote inference offline. Model requests follow your selected provider's data handling and pricing.
- Office support is for reading, not full Office editing. Optional legacy conversion still requires a supported local LibreOffice setup.
- The built-in webpage reader accepts public HTTP(S) pages on standard ports. Sites requiring downloads, popups, workers, or extra permissions should use **Open in browser**. Returning to a webpage replaced by another webpage reloads it.
- Diagnostic reports start from a real error and require review and consent. Nothing is uploaded automatically.
- Back up important work before trying a beta. Existing drafts and projects stay in the local daemon; this release adds no database migration.
