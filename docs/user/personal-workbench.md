# gogosling 使用说明：个人工作台

这份说明给要在自己电脑上完成文档、表格或文件修改的人。不需要了解内部构造。

文中的名称与界面一致：助手、任务、资料、项目、成果、版本、副本、文件修改。设置里的「智能体」就是助手。

本文第 1–6 节写的是 2026-10-12 已可在本机使用、尚未作为正式安装包发布的能力。第 7 节是还没有的设计，当前界面里没有这些按钮。

## 1. 开始之前

你需要：

- 一台已打开 gogosling 的电脑。桌面版打开后即可使用。
- 一个你自己的模型服务账号：服务地址、模型名称，以及该服务要求的密钥。
- 想交给助手的目标和可以附上的文件。没有文件也可以开始。

请先知道三件容易混淆的事：

1. **保存版本**把成果留在 gogosling 里，方便下次打开。它不修改你原来的文件。
2. **保存副本**或**导出**会另外生成一份文件，仍然不覆盖原文件。
3. **文件修改**才会改工作区里的某一个文件。它一定先给你看预览。状态没有变成「已应用」之前，目标文件不会按这次预览被改掉。

在 Windows 上可以做前两件事。这一版不能把修改写回原文件。

如果打开后看到的是「连接到守护进程」，说明当前不是桌面版的自动连接。向给你安装说明的人索取地址和访问令牌，填好后点「连接」。令牌只留在这次打开的页面里。

## 2. 十分钟完成第一件任务

按顺序做。某一步的按钮名称若略有不同，以你屏幕上的文字为准。

### 第一步：接上模型

1. 打开设置。
2. 进入「模型连接」。
3. 选择「新建供应商」。
4. 填写名称、类型、服务地址。需要密钥时填写密钥。密钥保存后不会再显示出来。
5. 点「测试连通性」。看到连通正常后，点保存。
6. 如果测试失败，先不要创建助手。对照本文第 6 节「连不上模型」。

### 第二步：准备一个助手

1. 在设置中进入「智能体」。
2. 点「新建智能体」。
3. 写下名称，选上一步的供应商和模型。
4. 在「自治档位」里选一种确认方式：
   - **全部审批**：会改动外界的操作都先问你。
   - **高风险审批**：命令、网络、发消息、删除这类先问你。
   - **沙箱内自动**：允许范围内自己做，超出范围仍会问你。
5. 保存。

不确定时，选「全部审批」。以后可以再改。改动会影响这个助手的所有任务。

### 第三步：开始一件事

1. 回到工作台，点「新建任务」。
2. 在输入框写下你要完成的事。也可以先点一个示例，它只会把句子放进输入框，不会发送。
3. 需要参考文件时，点加入资料或把文件拖进去。输入框会显示「本次参考」了几份。
4. 看输入区附近的助手、模型和目录是不是你要的。
5. 点「开始任务」。

没有写字、也没有文件时，点「新建空任务」。你可以稍后再写要求。

### 第四步：处理询问

如果出现「需要你的确认」：

1. 看这是哪个任务。
2. 看它要做什么、对哪个对象。
3. 同意这一次就点「批准一次」。只在你明确希望这个任务后面同类操作不再逐次询问时，才点「本会话内允许」。
4. 不同意就点「拒绝」。

### 第五步：留下成果

1. 回复出现后，点「保存初稿并编辑」。澄清式的短回复不会自动变成正式成果。
2. 在成果区修改。看到「已保存」表示这次编辑稿已经记下。
3. 确认内容后，点「保存新版本」。
4. 下次从左侧打开同一任务，就可以再看到这个版本。

到这里，第一件任务就完成了。

## 3. 界面里每个区域做什么

左侧是找路的地方：

- **新建任务**：回到开始页。
- **查找任务**：在已经加载出来的任务里搜索。
- **项目**：资料、任务和成果放在一起的地方。
- **定时任务**：到点在这台电脑上运行。不是普通聊天任务，也不会发到别的软件。
- **最近任务**：继续、固定、重命名、归档。
- **设置**：外观、模型、助手、技能与扩展、操作记录、资源与性能。这里没有消息连接，也没有云同步。
- **手机端应用**：正式下载地址公布后，设置或页脚会出现这一行。点开会到系统浏览器。它不登录，也不把电脑上的任务或文件送到手机。地址还没有公布时，这一行不会出现。

中间是任务本身：上面是目标和进展，下面是输入框。

右侧是成果。窗口较窄时，改成两个标签：「对话与进展」和「成果」。两个标签共用同一份编辑，切换不会把字弄丢。

输入框下面这行字是发送方式：Enter 发送，Shift+Enter 换行。

## 4. 核心功能

### 4.1 任务

任务就是一件持续的事。你可以补充要求、停止、归档后再恢复。

运行时你会看到这些状态：待开始、排队中、处理中、待确认、已完成、未完成、已停止。若显示「恢复中」或「状态未知」，先等它读完或去历史里核对，不要立刻再发同一句。

同一件任务还在处理时，不能同时再发一条。你可以先把下一句写在输入框里，这轮结束后再发。

### 4.2 资料

资料是你交给这件任务参考的文件。

- 放进项目时，不会自动全部选中。
- 只有打勾的文件会跟这条消息一起发出。
- 取消勾选或从项目移除，不会删除电脑上的原文件，也不会改掉已经发出的消息。
- 勾选资料不会让助手突然可以去读更多文件夹，也不会把它原来能读的工作区关掉。

### 4.3 项目

项目用来把同一个助手的资料、任务和成果放在一处。一个项目固定使用创建时选的那个助手。

项目归档后，不能从这里再开始新任务，但已经在进行的任务还能打开。恢复项目后可以再开始。

### 4.4 成果、副本和原文件

| 你点的 | 结果 |
|---|---|
| 保存初稿并编辑 | 在 gogosling 里建立第一版正式成果 |
| 保存新版本 | 再留一版。旧版还在，只供查看 |
| 保存副本 | 在当前工作区的附件目录另存一份 |
| 导出 | 下载或另存一份到你指定的位置 |
| 文件修改里的申请应用 | 按预览改工作区中的那一个目标文件 |

查看旧版本时，你正在写的内容不会被换掉。若要用旧版内容继续，点恢复，保存时会变成新的一版，旧版不会被删掉。

### 4.5 优化提示词

输入框里有字时，可以点「优化提示词」。

- 它只改你还没发出的那段文字。
- 不会读取附件，也不会把任务发出去。
- 你可以保留原文、自己改候选、写下调整意见后再调一版、替换进输入框，或事后撤销。
- 这次优化会计入你在模型服务商那里的用量，但不会算进当前任务那一轮的用量数字。

### 4.6 文件预览

点开附件、资料或工作区文件即可阅读，关掉就结束这次阅读。

可以直接阅读的包括：常见文本和代码、网页的静态内容、Word / PowerPoint / Excel 的新格式、OpenDocument、PDF、常见图片、音频和视频，以及压缩包里的文件名列表。

请注意：

- 表格里看到的是已经保存在文件中的数值或公式文字，不会替你重算。
- 幻灯片和文档的复杂版式、动画、宏可能省略。
- 旧版办公文件需要电脑上已有转换能力。没有时，界面会让你下载，不会把文件传到网上转换。
- 加密的 PDF 需要你先在原来的软件里解除加密。
- 内容过长时只显示一部分，下载可以得到完整文件。

### 4.7 用量

输入区可以打开本轮用量，分别是输入、输出和缓存读取的 token。没有数字时会写「服务尚未提供本轮用量」。金额以你的模型服务商账单为准，这里不估算价钱。

## 5. 分步操作

### 5.1 从项目开始一件任务

1. 点「项目」，再点「新建项目」。
2. 填写名称和说明，选一个助手，保存。
3. 打开项目，进入「资料」，把文件加进来或拖进去。
4. 只勾选这次要用的文件。页面上会显示已选几份。
5. 点「开始任务」，写上目标并发送。
6. 做完后，在项目的「成果」里可以看见已保存的版本。

如果提示部分资料已不可用：先点移除那些不可用项，再开始。你已经写的文字会留着。

### 5.2 把一句要求写得更清楚再发送

1. 在输入框写上你的原话。
2. 点「优化提示词」。
3. 等候选出现。需要更短或保留某种格式时，点「调整」，写下意见，再点「按意见调整」。
4. 满意后点「替换输入」。
5. 回到输入框检查，确认后再按 Enter 或点发送。
6. 若替换后反悔，点「撤销优化」。

点「保留原文」或关掉窗口，输入框维持打开前的内容。

### 5.3 修改已保存成果并留下新版本

1. 打开任务，在成果区选中已保存成果。
2. 直接编辑。等待状态从「保存中」变为「已保存」。
3. 点「保存新版本」。
4. 若要对照旧版，打开「版本历史」。这时你的当前编辑还在。
5. 只有在你确认「以此内容恢复为新版本」之后，保存才会把那一版历史写成新版本。

如果提示已经有更新的正式版本：你的编辑仍在。选「载入最新内容」会改用新版本继续；选「保留我的编辑并继续」会在你确认后，以最新版为基准另存一版。

### 5.4 在 macOS 上把成果写回一个文本文件

Windows 请不要按本节操作。请用「保存副本」或「导出」。

1. 先完成「保存新版本」。没有正式版本时，不能生成文件修改预览。
2. 打开成果区的「文件修改」。
3. 在目标文件中填写工作区里的相对路径，例如 `notes/说明.txt`。不要填写电脑上的整段绝对路径。
4. 修改方式选「新建文件」或「替换文件」。
5. 点「生成预览」。读完新增了哪些行、删除了哪些行。此时文件还没改。
6. 确认后点「申请应用」。
7. 出现确认框时，只批准这一份预览。
8. 等到状态变成「已应用」，再去文件夹里查看。

若要撤销：

1. 在这条已应用的记录上点「预览撤销」。
2. 看撤销预览。如果当初是新建，撤销会删除这个文件，确认框会按删除来问你。
3. 再次同意后，才会执行。文件如果已经又被改过，撤销不会进行。

### 5.5 固定、归档和找回任务

1. 在最近任务上打开任务操作。
2. 「固定到侧栏」后，它会留在容易点到的位置。取消固定不会删除任务。
3. 「归档」后不能再发消息。需要继续时点「恢复」。
4. 查找只覆盖已经加载出来的任务。没找到时，先加载更多，再搜索。

### 5.6 调整同时能做几件事

1. 打开设置中的「资源与性能」。
2. 把「同时执行」改成 1 到 8。默认是 2。
3. 保存。已经在做的任务会先做完，不会被中途掐断。
4. 排队最多 32 个。排队时还不会开始调用模型。

你自己刚发出的任务会排在定时任务前面。同一个工作目录里的任务会一个接一个做。正在等你确认的任务，也算占用一个名额。

### 5.7 离开和退出

- 还有没发出的字、正在上传的文件，或成果没保存完时，离开会先问你。
- 桌面版点关闭窗口，是隐藏到托盘，任务继续跑。
- 真正退出前，会先让你处理未保存内容，然后再停止本机服务。
- 还没上传成功的本地文件，下次打开要重新选。已经保存的文字和已经上传的资料不用重选。

## 6. 常见问题与故障排查

先看提示停在哪一环，再按那一环做一步。做完再看结果，不要连续重复发送，也不要反复保存或反复申请写回。

| 你看到的词 | 停在 | 先做 |
|---|---|---|
| 无法连接、访问令牌无效 | 连接 | 核对地址和令牌。不要开始新任务 |
| 先配置助手、连通失败 | 准备 | 到模型连接测试，再确认助手已启用 |
| 正在创建、正在加入资料、正在提交、无法确认是否已经开始 | 开始 | 到已有任务里核对这句话在不在。不要马上再点开始 |
| 排队中、处理中、未完成、已停止、状态未知 | 运行 | 等待、停止，或看失败说明。未知时先核对，不自动再发 |
| 需要你的确认、等待审批 | 确认 | 看清是哪件任务、做什么。不同意就拒绝 |
| 保存中、保存失败、草稿有更新 | 草稿 | 先留在当前窗口。失败就重试；有更新就先看两份内容再选 |
| 版本冲突、副本未保存 | 成果 | 编辑先留着。按提示载入最新内容，或保留编辑后再存一版 |
| 已预览、文件已变化、需要核对、申请结果未知 | 文件 | 预览不等于已经写入。未知或需要核对时先刷新状态，不要再申请一次 |
| 优化模块未加载、正在优化、忙碌 | 优化 | 原文还在。忙碌就等任务少一些再试 |
| 当前连接尚不支持 | 能力 | 用原来的任务和保存副本。不要把隐藏的按钮当成故障 |

提示应同时说明：停在哪里、已经保住什么、没有发生什么、下一步只做哪一件事。若详情里有任务名称、环节、状态和时间，排查时整段照抄，不要只说「失败了」。

下面按现象展开。若和上表冲突，以上表的「先做」为准。

这几件事是预期结果，不必反复重试：

- 换了一个助手后，输入框里应是这个助手自己还没发出的内容。
- 开始之后马上打开另一件任务，页面留在新任务上。先前那件要回去才能看到。
- 两份同名文件会同时留下，不会后一份盖掉前一份。
- 任务已经停止，仍可以打开已经保存的成果。
- 两件任务都在等你确认时，只处理你正在看的那一件。任务名称还没显示出来时，先不要点批准。
- 关掉窗口收到托盘，已经开始的那一轮还在。连上了却没有下文时，先核对，不要再点一次开始。
- 模型连不上时，按连接或配置失败处理。这里不会把它说成额度已经用完。

### 开始按钮没有反应，或提示先配置助手

1. 打开设置 → 模型连接，确认供应商已保存，并且测试连通是成功的。
2. 打开智能体，确认助手已启用，并且选了这个供应商。
3. 回到开始页再试。

### 测试连通失败

1. 检查地址是否完整，并且是你的服务商给的地址。
2. 检查密钥是否填对。留空表示不修改已保存的密钥；第一次必须填写。
3. 保存后再测试。发现模型使用的是已保存的连接。
4. 仍然失败时，先在服务商自己的页面确认账号可用。本文不能看到对方的账单或故障。

### 点了开始，不确定任务有没有建出来

1. 不要马上再点一次。
2. 看页面是否已给出阶段：正在创建、正在加入资料，或正在提交。
3. 若提示暂时无法确认，打开已有任务或历史记录，看这句话在不在。
4. 确认没有重复之后，再决定是否重新开始。

### 提示会话已有未结束的运行

等它变成已完成、未完成或已停止，或点「停止」。停止只结束这一轮，不删除任务。

### 草稿显示保存失败

1. 先不要关闭窗口。当前文字还在页面上。
2. 点「重试」。
3. 变成「已保存」后再离开。
4. 若变成「草稿有更新」，先看另一份内容，再选择保留当前或改用那一份。

### 重新打开后，选过的文件不见了

还没上传完成的文件不能跨重启保留。请重新选择。已经上传并打勾发出去的资料，仍在原任务里。

### 成果里的字和文件夹里的文件不一样

这是预期情况。保存版本只更新 gogosling 里的成果。要改文件夹里的文件，请按第 5.4 节做文件修改，并等到「已应用」。

### 文件修改一直停在「已预览 · 未写入」

预览本身不会写入。请点「申请应用」，并在确认框里批准。若工作区正在运行别的任务，会提示稍后重试，先等那次运行结束。

### 状态是「文件已变化」

目标文件在预览之后又被改过。gogosling 停下来了，没有覆盖那份新内容。请先看现在的文件，再重新生成预览。

### 状态是「需要核对」

这次写入没能确认完成。不要反复点申请。点「核对状态」。系统不会自动再写一遍，也不会拿一份来源不明的文件覆盖新内容。若你无法判断文件夹里哪一份才是对的，先不要删除旁边留存的原件。

### 状态是「申请结果未知」

先点核对或刷新。不要再提交一次。核对完成前，不要假定文件已经改好或完全没改。

### 优化提示词失败或很久没有结果

1. 原文还在，任务消息不会因此增加。
2. 若提示忙碌，等当前任务少一些再试。
3. 若提示模块没有加载成功，刷新页面后再试。
4. 可以点「重新优化」。空结果或不完整的结果不会替换你的原文。

### 文件打不开预览

1. 看提示是格式不支持、文件过大、已加密、内容损坏，还是缺少本地转换能力。
2. 点「下载」，用你平时的软件打开。
3. 点「刷新」再读一次。若提示文件已变化，说明阅读过程中文件被改过。
4. 一个文件失败不影响其他任务。

### 左侧找不到以前的任务

1. 看是否在「已归档」里。
2. 搜索只查已经加载的任务。点加载更多后再搜。
3. 本版列表最多显示 200 项。超过时，没显示出来不等于已经被删除。

### 用量是空的，是不是没花钱

不是。空的意思是这一轮没有拿到用量数字。是否产生费用，以模型服务商的账单为准。

### 关闭窗口后任务停了吗

桌面版关闭窗口是收到托盘，任务还在。要从托盘真正退出时，会先问你未保存的内容。

### 删除任务会不会把我的文件删掉

不会删除工作区里的文件。它会删除这件任务里的消息、草稿和成果版本。删除前如果成果还有未保存编辑，要先保存或还原。

删除助手也一样：相关任务、项目、草稿和成果版本会去掉，工作区文件保留。

## 7. 还没有的能力

下面这些是已经定下来、但当前版本还不能用的设计。界面里现在没有对应按钮。若以后出现，也要等那一项单独可用，而不是一次性全部出现。

### 当前目标

现在任务里能看到的是最初那句话和最近一次补充。以后会多一行「当前目标」，但只有你确认之后才算数。

- 「整理当前目标」只生成一段草稿给你看，不会把任务发出去，也不会自动接着做。
- 你点取消，就保持「尚未整理」或上一次确认过的句子。
- 你后来又补充了要求，当前目标不会自己改写，而会注明它是在这次补充之前确认的。
- 没有这行之前，不要把最初那句话理解成「后来的修改已经合并进去了」。

### 列表和查找

任务、项目、资料、成果现在最多能看到 200 项。没显示出来不等于被删掉。

以后会先做到「还有更多」，可以继续往下看。全文查找是另一项：在它出现之前，搜索框仍然只查已经加载出来的任务。查找失败时，不会把「没查完」说成「没有这个任务」。

### 用量和价钱

现在只显示这一轮拿到的 token。没有数字就是还没提供，不是没花钱。

以后会把「这一轮任务」「优化提示词」「服务商返回的金额」分成三块。服务商没给金额时，不会出现 0 元，也不能在这里填单价。本产品不提供余额，也不按金额自动停用。

### 在 Linux 或 Windows 上改原文件

现在只有 macOS 可以按第 5.4 节写回一个文本文件。Linux 和 Windows 请继续用保存副本或导出。

以后若某个系统也可以写回，确认方式与现在相同：先看预览，只批准这一份，状态变成「已应用」才算改过。一次仍然只改一个文本文件。不会因为换了系统，就变成一次改很多文件。

另外，以后人自己发起的写回，即使用助手设成「沙箱内自动」，也仍要单独确认这一份预览。在那项更新出现之前，仍以你眼前有没有确认框、状态有没有变成「已应用」为准。

### 结果未知时再点一次

现在如果不确定发出去没有，要先打开已有任务核对，不要马上再点。这个做法保持不变。

以后同一次点击在核对完成前不能变成第二次发送。你改了文字或资料之后再发，才会是新的一条。

### 团队

个人项目、草稿和成果不会在加入团队时被自动公开或搬走。文件修改仍然只能在这台电脑上确认。没有团队入口时，按本文第 1–6 节使用即可。

### 请不要等待这些按钮

当前版本也不会提供：打开任务就自动继续、勾选资料就限制助手只能读这些文件、一个项目里多个助手、电脑合上后改到云端继续、助手再去调用另一个助手、在预览里直接改办公文件、由这里计算套餐余额、消息连接、在线转换、分享链接，或到网上抓取内容。

手机和电脑之间现在没有同步。公布手机端应用之后，也只是多一个打开下载页的链接。
