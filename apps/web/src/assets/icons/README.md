# Local UI icons

`person-fill.svg` is the unmodified [Person fill icon](https://icons.getbootstrap.com/icons/person-fill/) from [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/blob/v1.13.1/icons/person-fill.svg). It supplies the default settings avatar and is bundled locally; the app makes no image request to an external service.

The upstream MIT license is retained in [the bundled MIT license](../../../public/licenses/bootstrap-icons.txt). Other interface icons continue to use the app's existing icon component.
